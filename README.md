# SSW Agriculture Website — HD Reader V2

Website package for GitHub + Netlify.

## Included
- Pertanian/Pertanaman ebook: 102 HD pages
- PM ebook: 84 HD pages
- PM practice flow unified with Pertanian-style learning flow
- PM topics, summaries, page-based practice, 92-question bank
- Separate Pertanian / PM ranking UI (Supabase-backed in the app)
- Unified ebook reader: back button, table-of-contents drawer, page jump, progress, bookmarks, zoom, fit, fullscreen, swipe navigation
- Existing Supabase Auth, profile/progress sync, quiz history, annotations, and ranking integration preserved
- HD book images are externalized under `assets/` without recompression/resizing

## Deploy
Use the repository as the Netlify publish directory. `index.html` is the entry point.

For GitHub + Netlify continuous deployment, connect the repository to Netlify and deploy from the production branch.
